SQL do passo 2 — para colar no Supabase

Isto liga a taxa de R$ 1,00 por inscrição e a tabela da cobrança Pix. Pode rodar quantas vezes quiser: não apaga nada.

  1. Clique no botão abaixo — ele copia todo o SQL para a área de transferência.
  2. No Supabase, abra SQL Editor → New query.
  3. Clique dentro da área de texto e cole (Ctrl + V).
  4. Clique em Run. Tem que terminar com Success.

Se o botão não funcionar: clique dentro da caixa abaixo, aperte Ctrl + A (seleciona tudo) e Ctrl + C (copia).
