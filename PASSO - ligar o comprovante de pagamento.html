Ligar o anexo do comprovante — SQL para o Supabase

Isto cria a tabela e o cofre onde ficam os comprovantes que as pessoas anexam depois de pagar. Pode rodar quantas vezes quiser: não apaga nada.

  1. Clique no botão abaixo — ele copia todo o SQL.
  2. No Supabase, abra SQL Editor → New query.
  3. Clique dentro da área de texto e cole (Ctrl + V).
  4. Clique em Run. Tem que terminar com Success.

Se o botão não funcionar: clique dentro da caixa abaixo, aperte Ctrl + A e Ctrl + C.

Enquanto isto não for rodado, o site continua funcionando normal — o campo de anexar simplesmente não aparece.
