TRAVA 1. Ligar o envio de e-mail (Brevo → Supabase)

Sem isto ninguém entra — nem você, nem o coordenador, nem os inscritos. O login é só por link no e-mail.

  1. No Brevo, valide o remetente. Menu Senders, Domains & Dedicated IPs → Senders → Add a sender, cadastre contato.altapista@gmail.com. O Brevo manda um e-mail de confirmação para esse endereço — abra e clique no link. Sem isso o envio é recusado depois, sem explicar o motivo.
  2. Pegue a chave SMTP. No menu do seu nome, SMTP & API → SMTP. Anote o Login (algo como 8a1b2c001@smtp-brevo.com). Clique em Generate a new SMTP key e copie a chave — ela só aparece uma vez.
  3. No Supabase, em Project Settings → Auth → SMTP Settings, ligue Enable Custom SMTP e preencha:
    Sender emailcontato.altapista@gmail.com
    Sender nameAlta-Pista
    Hostsmtp-relay.brevo.com
    Port587
    Usernameo Login do passo 2 (…@smtp-brevo.com)
    Passworda SMTP key gerada no passo 2
  4. Logo abaixo, em Rate limits, suba o limite de e-mails por hora (ex.: 100). Ele continua baixo mesmo com o SMTP próprio ligado — é aqui que todo mundo tropeça achando que já resolveu.

Pronto quando: você sai da sua conta no site, pede um link de acesso e ele chega em segundos, com “Alta-Pista” no remetente.

TRAVA 2. Montar o banco inteiro (um arquivo só)

Supabase → SQL Editor → New query. Garante a taxa de R$ 1,00 por inscrição, a tabela da cobrança Pix e tudo o que veio depois.

  1. Abra o arquivo supabase\_rodar-tudo-de-uma-vez.sql (na pasta do projeto).
  2. Selecione tudo (Ctrl+A), copie, cole no SQL Editor e clique em Run.
  3. Deve terminar com Success. Pode rodar de novo à vontade — não apaga nem estraga nada, mesmo com inscrições abertas.

Se aparecer um aviso pedindo para ligar o pg_cron em Database → Extensions: ligue e rode o arquivo mais uma vez.

TRAVA 3. Apontar o endereço do site no Supabase

Supabase → Authentication → URL Configuration.

  • Site URL: https://alta-pista.vercel.app
  • Redirect URLs: a mesma linha, https://alta-pista.vercel.app (e http://localhost:3000 se um dia for testar na sua máquina).

Sem isto o link do e-mail leva para um endereço errado e o login falha.

TRAVA 4. Virar organizador (você e o coordenador)

Primeiro entre no site uma vez com o seu e-mail (e peça para o coordenador entrar com o dele), só para as contas existirem. Depois, Supabase → SQL Editor:

insert into public.organizadores (user_id)
select id from auth.users
where email in ('aldemir66383@gmail.com', 'EMAIL-DO-COORDENADOR')
on conflict do nothing;

Troque EMAIL-DO-COORDENADOR pelo e-mail real. Recarregue o site: a aba Painel aparece.

TRAVA 5. Cadastrar o Pix e publicar o evento

No site, aba Painel.

  1. Em Identidade do site: iniciais, nome, cor, rodapé (contato/WhatsApp/Instagram).
  2. Salve os dados do Pix: chave, nome do recebedor exatamente como está na conta, cidade.
  3. Crie o evento (nasce como rascunho), monte lotes, edital e perguntas — o botão Usar o conjunto de corrida já traz os campos padrão.
  4. Clique em Publicar. Só aí o evento aparece no site.

A confirmação do Pix, por enquanto, é manual: o inscrito mostra o comprovante e você clica em Marcar pago no painel. Isso já funciona hoje. A confirmação automática é o passo 7.

DEPOIS 7. Confirmação automática do Pix (Mercado Pago)

Enquanto não estiver ligado, o site usa QR estático + Marcar pago manual. Dá para abrir as inscrições sem isto.

  1. Mercado Pago → Seus negócios → Configurações → Gestão e desenvolvimento → Suas integrações: crie uma aplicação e pegue o Access token (comece pelo de teste, TEST-…; depois troque pelo de produção APP_USR-…).
  2. Vercel → projeto alta-pista → Settings → Environment Variables. Adicione:
    SUPABASE_URLhttps://nvbkofitjjragqrutull.supabase.co
    SUPABASE_SERVICE_ROLE_KEYa secret key em Supabase → Project Settings → API Keys — é segredo, nunca vai para o site nem para o Git
    MERCADOPAGO_ACCESS_TOKENo token do passo 1 — é segredo
    MERCADOPAGO_WEBHOOK_SECRETopcional: a assinatura secreta que o Mercado Pago mostra ao configurar Webhooks
  3. Na Vercel, faça um Redeploy para as variáveis valerem.
  4. Mercado Pago → Webhooks: URL https://alta-pista.vercel.app/api/webhook-mercadopago-pix, evento Pagamentos.
  5. Teste: faça uma inscrição e pague (usuário de teste no sandbox, ou valor pequeno na produção). Rode o atalho Conferir pagamento automatico.cmd — a inscrição deve virar paga sozinha em menos de um minuto.
